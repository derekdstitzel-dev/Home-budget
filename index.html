Backup and privacy

This version saves your data locally in this browser on this device. It does not upload your banking information or connect to a bank. Browser storage can be cleared, so export backups regularly.

Automatic syncing & notifications

Not connected This standalone version supports manual CSV imports. Real automatic syncing requires a secure server, a regulated bank-data provider, encrypted storage, user authentication, and transaction webhooks or scheduled polling.

When implemented, the server would deduplicate posted transactions, classify known merchants, and push only unidentified purchases to your review queue. Never place bank API secrets in this HTML file.

Notifications work only where supported and while this app is open; no background bank alerts yet.
